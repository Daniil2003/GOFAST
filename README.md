# GoFast — аналитика тарифов кикшеринга

Статистический анализ поведения пользователей кикшеринга GoFast: сравнение тарифов
**free** и **ultra** по частоте поездок, времени, дистанции и выручке. Данные за 2021 год.

## Данные

`datasets/` (1 534 пользователя, 17 973 поездки, период 2021-01-01 — 2021-12-30):

| Файл | Содержание |
|---|---|
| `users_go.csv` | `user_id, name, age, city, subscription_type` — 835 free / 699 ultra |
| `rides_go.csv` | `user_id, distance (м), duration (мин), date` |
| `subscriptions_go.csv` | Тарифы: free = 50 ₽ старт + 8 ₽/мин; ultra = 0 ₽ старт + 6 ₽/мин + 199 ₽/мес |

## Структура

```text
gofast_eda.py              — разведочный анализ (EDA) + 10 графиков
gofast_stats_common.py     — общие утилиты: var/mean, поправка Холма, загрузка данных
gofast_counts_test.py      — тест частоты поездок (free vs ultra)
gofast_time_test.py        — тест времени поездки + суммарного времени
gofast_distance_test.py    — тест дистанции против порога 3130 м
gofast_revenue_monthly.py  — помесячная выручка и ARPU
gofast_support_test.py     — заглушка гипотезы про техподдержку (данных нет)
output/                    — графики (PNG) и текстовые отчёты скриптов
```

## Запуск

Требуется: Python 3.9+, `pandas`, `numpy`, `scipy`, `matplotlib`, `seaborn`
(`statsmodels` — опционально, для NB GLM).

```bash
python3 gofast_eda.py
python3 gofast_counts_test.py
python3 gofast_time_test.py
python3 gofast_distance_test.py
python3 gofast_revenue_monthly.py
python3 gofast_support_test.py
```

Каждый скрипт печатает результаты в консоль и сохраняет отчёт в `output/*.txt`
(`revenue_monthly` — дополнительно `output/revenue_monthly.csv`).

## Ключевые результаты

| Гипотеза | Метод | Результат |
|---|---|---|
| Ultra ездят реже | Mann-Whitney U, Welch, IRR | Подтверждена: 13.74 vs 9.30 поездок/год, p≈6e-103, IRR=0.677, эффект во всех 12 месяцах и 8 городах |
| Ultra тратят больше времени на поездку | Welch на пользовательских средних, cluster bootstrap, MWU | Подтверждена: +1.05 мин/поездка, 95% CI [+0.86; +1.24], p≈2e-26. Суммарно за год ultra меньше на 68.5 мин (следствие редких поездок) |
| Дистанция ≤ 3130 м | Одновыборочный t-тест, биномиальный тест доли | Не отвергнута: ultra 3115 м, free 3028 м; 49.97% поездок > 3130 м. «Оптимальность для износа» непроверяема — данных об износе нет |
| Выручка ultra выше помесячно | Парный t-тест ARPU за 12 мес. | Зависит от допущения: при оплате только активных месяцев ultra −24 ₽/мес (p≈7e-06); при оплате всех ultra весь год ultra +67 ₽/мес |
| Обновление серверов снизило обращения в поддержку | — | Блокер: нет таблицы обращений и даты деплоя. Каркас DiD/ITS готов в `gofast_support_test.py` |

## Ограничения

- Самоотбор в тариф — сравнения описательные, причинный вывод невозможен.
- Нет дат регистрации/оттока — каждый пользователь считается наблюдавшимся весь год.
- Абонплата 199 ₽/мес — допущение, чувствительность показана в двух вариантах.
- У каждого пользователя ≥ 2 поездки — средние смещены вверх относительно всей базы.
